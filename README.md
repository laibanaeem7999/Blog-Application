# Blog Application

A full-stack Blog Application built during my web development internship.

## Features

- User registration and login
- JWT-based authentication
- Protected dashboard routes
- Create blog posts
- View blog posts
- Edit blog posts
- Delete blog posts
- User-specific dashboard
- Latest blogs displayed on the home page
- User profile functionality
- Logout functionality
- MongoDB database integration
- Responsive user interface

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JSON Web Token (JWT)
